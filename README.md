# Email Automation

Production-oriented bulk email and follow-up automation service.

## Scope
- Import contacts from CSV/XLSX
- Normalize and de-duplicate recipient email addresses
- Personalize job outreach templates
- Queue-based sending with rate limits, retries and idempotency
- Per-recipient delivery state and follow-up scheduling
- Unsubscribe/suppression support
- Dry-run mode and audit logging

## Compliance
Use only for recipients you are permitted to contact. Respect applicable anti-spam/privacy laws, sender-provider limits, opt-outs, and unsubscribe requests. Do not use the system to evade provider controls or send unsolicited high-volume spam.
